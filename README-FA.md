# مدیریت بلوک — نسخه آفلاین Android

این پروژه برای تبدیل برنامه HTML «مدیریت بلوک» به APK واقعی Android آماده شده است.

## ویژگی‌های پروژه
- اجرای کاملاً آفلاین داخل WebView
- ذخیره داده‌های ساکنین، قبوض و هزینه‌ها در SQLite اندروید
- حفظ رابط فارسی RTL برنامه
- انتخاب فایل برای ورود Excel و بازگردانی Backup
- ذخیره فایل‌های خروجی در Downloads اندروید
- حذف telemetry، rrweb و ارتباطات DesignArena
- بدون Cloudflare، Supabase، سرور یا VPN

## ساخت APK بدون کامپیوتر
اگر فقط گوشی دارید، ساده‌ترین مسیر این نسخه استفاده از GitHub Actions است:

1. یک Repository جدید و خالی در GitHub بسازید.
2. تمام فایل‌های این پروژه را در branch `main` قرار دهید.
3. از GitHub وارد `Actions` شوید.
4. workflow با نام `Build Android APK` را انتخاب کنید.
5. روی `Run workflow` بزنید.
6. پس از پایان موفق، در همان اجرای workflow بخش `Artifacts` فایل `MahestanOffline-debug-apk` را دانلود کنید.
7. ZIP آرتیفکت را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## نکته
این APK نسخه debug است و برای نصب مستقیم روی گوشی مناسب است. پس از تست کامل، می‌توان نسخه release امضاشده تولید کرد.
